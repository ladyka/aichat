# Веб-поиск

[Вторая версия](index.md), витрина.

**Состояние: сделано.** Рука `web_search` в `/api/chat`. Службы: Bing Web Search и Яндекс XML. Каждая включается своими ключами; без ключей руки нет.

## Что это

Ещё одна рука в чате: модель уходит искать в интернете, когда ответа нет в её памяти. Не отдельный чат и не отдельный экран — тот же `/api/chat` и тот же список инструментов. У витрины это меняет не набор умений, а качество ответов на любой вопрос.

## Как устроено

- **Провайдеры.** Bing: `BING_SEARCH_API_KEY`, запрос на Bing Web Search v7. Microsoft сняла этот API 11 августа 2025; если подписка ещё отвечает, адрес можно задать в `BING_SEARCH_ENDPOINT`. Яндекс XML: облачная пара `YANDEX_SEARCH_API_KEY` и `YANDEX_SEARCH_FOLDER_ID` (`folderid` + `apikey`) либо классические `YANDEX_XML_USER` и `YANDEX_XML_KEY`. Облачная пара важнее. Адрес по умолчанию — `https://yandex.ru/search/xml`.
- **Источники в ответе.** Модель получает заголовок, ссылку и фрагмент с именем службы (Bing или Яндекс) и должна показать ссылки. Без ссылок ответ неотличим от выдумки.
- **Лимит.** Суточный потолок `WEB_SEARCH_DAILY_LIMIT` (по умолчанию 20 вызовов на человека, сутки UTC). Счётчик — таблица `web_searches`. Полный ledger — [биллинг](billing.md).
- **Осторожность с исходящими запросами.** В интернет уходит только текст запроса, и только на фиксированные адреса Bing и Яндекса. Переходы по чужим адресам инструмент не выполняет.
- **Задержка.** Поиск идёт между шагами ответа, как остальные руки. Пока он работает, в чате строка «Ищу в интернете…». Сбой одной службы не прячет ссылки другой.

## Почему отдельная работа

Рука меняет то, как модель отвечает вообще, а не добавляет умение к случаю. Ей нужны свой лимит, свой лог стоимости и честная строка на `/privacy` о том, куда уходит запрос — как это уже сделано для погоды и картинок.

## Что ожидает диктофон

Ничего специального: в диктофоне справа работает тот же `/api/chat`, инструменты подключаются на сервере (`enabled_tools()`), поэтому поиск появится там сам, без единой правки фронта.
