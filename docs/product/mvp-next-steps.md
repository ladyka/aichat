# MVP и следующие шаги

Практический план поверх [видения](vision-belarus.md). Связь с текущим кодом: `aichat` уже даёт чат + OpenAI-совместимый API на OpenRouter (free-модели) — удобная база для узкого ассистента. Runtime: Python 3.13+ и Node.js 24+ ([стек](../dev/runtime.md)).

Публичная витрина — для обычных людей; компании — отдельный LibreChat во **версии 2**. Этот чат на LibreChat не меняем. Версии: [roadmap](roadmap.md). Что уже сделано в v1: [план и факт](v1.md). Аудитории: [две аудитории](audiences.md).

Ниже — черновик **длинного** продуктового горизонта (egov, один госценарий), не список работ версии 1. В v1 из нового остаётся только skills и каталог.

## Что важно сейчас

1. **Один кейс.** Выбрать одну решаемую боль (например: «как оформить пособие по уходу за ребёнком»), не весь egov сразу.
2. **Юридическая проверка.** Санкции и доступ к провайдерам LLM из РБ; требования ОПД к хранению запросов и ПДн.
3. **Выбор LLM-слоя.** Сейчас — OpenRouter free через `aichat`. Альтернатива при ограничениях: self-host (Llama / Mistral) на VPS в допустимой юрисдикции.
4. **Пользовательский путь.** Первый вопрос → язык/контекст → ответ со ссылками → (позже) статус заявки через интеграцию.

## Предлагаемые шаги MVP

| Шаг | Что сделать | Ожидание |
|-----|-------------|----------|
| 1 | Веб-чат (уже есть в aichat) + системный промпт под кейс | Узкий ассистент без «универсальности» |
| 2 | База знаний / ссылки на официальные страницы по кейсу | Ответы с источниками, меньше галлюцинаций |
| 3 | Одна интеграция (если API есть) или честный «ручной» статус | Реальная польза, не только болтовня |
| 4 | Канал доставки (сайт и/или Telegram) | Обратная связь от первых пользователей |
| 5 | RU + BE в ответах/UI | Локализация без раздувания scope |

!!! tip "Бюджет"
    Точные цифры зависят от хостинга LLM и объёма трафика.
    Пока достаточно текущего shared hosting + OpenRouter free; GPU self-host — отдельное решение после проверки спроса.

## Открытые вопросы (для продукта)

1. На каком **одном** виде сервисов сфокусировать первый релиз?
2. Есть ли опыт/доступ к API госуслуг или банков?
3. Бюджет на MVP (хостинг, юрист, маркетинг)?
4. B2C для граждан или сразу B2B (API для банков/госа)? *(черновик ответа: витрина `aichat` — B2C; B2B — отдельный LibreChat, не вместо витрины.)*

## Итог

Потенциал есть за счёт реальной боли (бюрократия, быт) и локального контекста. Успех = **один кейс**, прозрачность, официальные источники, затем расширение. Техническая база `aichat` (чат + токены + прокси) подходит как старт; доменный продукт поверх неё ещё предстоит выбрать и сузить.
