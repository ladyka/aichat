# О сервисе aichat

**aichat** — веб-чат с языковой моделью для обычного человека: открыл сайт, вошёл, спросил. Не IDE, не корпоративный шлюз, не конструктор агентов.

Рядом с болтовнёй сервис умеет опереться на руки: время, погода, картинка, заказ пиццы с pzz.by, заметка к разговору. Модель отвечает текстом; за фактом и действием ходит ваш сервер.

Технически это ещё и OpenAI-совместимый API (`/v1/models`, `/v1/chat/completions`) с токенами `aichat_…`. Для витрины это задний двор, не лицо продукта.

## Для кого

Для людей «с улицы» в Беларуси и рядом: русский язык, простой вход (почта или Google/Apple), без выбора модели на каждом шаге. Модель задаётся в настройках.

Компаниям с SSO, ролями и агентами этот репозиторий не обещает контур. Их дверь — отдельный LibreChat во [второй версии](roadmap.md). Разведение аудиторий: [две аудитории](audiences.md).

## Чем не является

Не заменой Cursor. Не LibreChat. Не универсальным «как ChatGPT, только наше» с зоопарком провайдеров на экране чата. Не обещанием госуслуг в первой версии.
