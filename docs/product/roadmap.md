# Roadmap

Две версии. Витрина для людей живёт в этом репозитории. Контора — позже и рядом, не вместо.

Подробности v1: [план и факт](v1.md). Аудитории: [две аудитории](audiences.md). О сервисе: [о aichat](about.md).

## Версия 1 — витрина для обычных людей

| | Содержание |
|---|------------|
| **Факт** | Чат, вход, модели, API, шаринг, заметка, руки: время, погода, картинка, pzz, загрузка по URL |
| **План (единственное новое)** | Skills и каталог skills |
| **Не войдёт** | LibreChat, корпоративный контур, биллинг, новые крупные фичи сверх skills |

Закрытие v1 = факт стабилен + каталог skills работает для витрины.

## Версия 2 — компании и LibreChat

Не замена `aichat`. Второй контур:

- отдельный деплой **LibreChat**;
- корпоративные пользователи: OAuth/SSO, роли, то, что нужно конторе;
- витрина v1 остаётся дверью для улицы.

Бытовые руки v1 в LibreChat не вырезаем из витрины. Если понадобятся там — обёртка снаружи (MCP или OpenAPI), это уже работа v2, не скрытый объём v1.
