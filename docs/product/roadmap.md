# Roadmap

Дорога короткая и нарочно узкая. Сначала доводим витрину для людей в этом репозитории. Потом, отдельно, ставим дверь для конторы. Второе не проглатывает первое.

О сервисе — [о aichat](about.md). Что уже сделано и что ещё должны skills — [версия 1](v1.md). Кто какой дверью входит — [аудитории](audiences.md).

## Версия 1

Витрина для человека с улицы. Факт уже держит чат, вход, модели, API, шаринг, заметку и руки: время, погоду, картинку, заказ с pzz, загрузку по ссылке. В план больше ничего крупного не записываем, кроме **skills и каталога skills**. Когда каталог заработает, а факт не будет стыдно показывать, версию можно закрывать.

Сюда не переезжают LibreChat, корпоративный контур и биллинг. Их отсутствие — не недоделка, а граница.

## Версия 2

Рядом, не вместо. Отдельный LibreChat для компаний: вход предприятия, роли, то, без чего служба безопасности не пустит модель внутрь. Люди с витрины туда сами собой не мигрируют.

Если конторе понадобятся те же погода и пицца, руки не вырезают из aichat. Их при необходимости обернут снаружи — это уже труд второй версии.

## Дальше

Госуслуги, ЖКХ, узкий казённый сценарий остаются в [видении](vision-belarus.md) и в [старом черновике MVP](mvp-next-steps.md). Пока нет отдельного решения, это не очередь ни первой, ни второй версии.
