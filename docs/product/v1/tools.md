# Руки

**Состояние: реализовано.**

## Что это для человека

Модель умеет не только говорить. Если для ответа мало её памяти, сервер сходит за часами, погодой, картинкой, меню пиццы или поправит заметку. Человек просит по-человечески — «какая погода в Минске», — а не выбирает функцию из списка.

Руки — обычные серверные tools, не MCP: модель просит вызвать функцию, сервер исполняет. Набор собирается на сервере, поэтому выключенный ключ убирает руку из списка сам, а не оставляет её молчащей.

## Что умеет

| Рука | Что делает | Чем ограничена |
|------|------------|----------------|
| `get_current_datetime` | текущие дата и время, при желании в часовом поясе | — |
| `get_weather`, `get_user_location` | погода по городу или по координатам браузера | нужен `OPENWEATHER_API_KEY`; геолокация работает только по HTTPS, координаты кешируются на 2 часа |
| `generate_image` | картинка через OpenRouter Images, файл в S3 Cloud.ru | нужны настройки S3; суточный потолок `IMAGE_GENERATION_DAILY_LIMIT`; в `/v1` не отдаётся |
| `download_file` | скачать страницу или текстовый файл по ссылке | до `DOWNLOADS_MAX_BYTES` (2 МБ), только http/https, адреса локальной сети закрыты |
| `read_chat_note`, `write_chat_note` | читать и писать markdown-заметку текущего диалога | только `/api/chat`, в публичный `/v1` не попадают |
| `pzz_search_menu`, `pzz_lookup_address`, `pzz_place_order` | меню, адрес и заказ с pzz.by | выключается `PZZ_ENABLED=0`; отправка на кухню — только после явного согласия и при `PZZ_ORDERS_ENABLED=1`; через чат проходит только оплата наличными курьеру |

## Где в коде

`app/tools.py` — описания инструментов, `enabled_tools()` и исполнение; `app/pzz.py` — клиент публичного API pzz.by; `app/storage.py` — S3 для картинок; `app/notes.py` — заметка; таблицы `downloads`, `generated_images`, `usage_logs`; флаги в `app/config.py`.

## Что осталось

Ничего. Новая рука — один инструмент в `app/tools.py` плюс флаг в конфиге, если ей нужен ключ. Долг: молчащие руки чинить по мере находок.

## Не входит

Биллинга нет: за картинки платят суточным лимитом и логом стоимости, а не балансом. Это работа [второй версии](../v2/billing.md), как и [веб-поиск](../v2/websearch.md) — ещё одна рука, которой пока нет.
