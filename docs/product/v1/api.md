# API

**Состояние: реализовано.**

## Что это для человека

Задний двор сервиса: тот же разговор, но по ключу, без окна чата. Токен `aichat_…` создаётся в `/settings` и предъявляется как `Authorization: Bearer`. Формат запросов и ответов — OpenAI-совместимый, чтобы клиентам не приходилось переучиваться.

## Что умеет

- `GET /v1/models` — список моделей, без авторизации.
- `POST /v1/chat/completions` — разговор по токену.
- На каждый токен — `API_DAILY_LIMIT` запросов в сутки (UTC); при превышении 429. Запросы из браузерного чата в этот лимит не входят.
- На пользователя — не больше `MAX_TOKENS_PER_USER` активных токенов; лишний можно отозвать.
- Токены и их расход видны в `/settings` (таблицы `api_tokens`, `api_token_usage`).
- Инструменты чата в `/v1` не попадают: заметка, погода, картинка и pzz остаются витрине. Так платная генерация картинок недостижима по утёкшему ключу.
- `api_check.py` — проверка токена против хоста.

## Где в коде

`app/routes/api.py` — `/v1/models`, `/v1/chat/completions`; `app/auth.py` — выпуск и проверка токенов; `app/routes/pages.py` — `/tokens` (создание и отзыв); `templates/settings.html` — блок токенов рядом с выбором модели; таблицы `api_tokens`, `api_token_usage`, `usage_logs`.
