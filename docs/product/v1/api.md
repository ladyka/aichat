# API

**Состояние: реализовано.**

## Что это для человека

Задний двор сервиса: тот же разговор, но по ключу, без окна чата. Токен `aichat_…` создаётся на `/settings`, в разделе «API-токены» (прямая ссылка — `/settings#api`), и предъявляется как `Authorization: Bearer`. Формат запросов и ответов — OpenAI-совместимый, чтобы клиентам не приходилось переучиваться.

## Что умеет

- `GET /v1/models` — список моделей, без авторизации.
- `POST /v1/chat/completions` — разговор по токену.
- На каждый токен — `API_DAILY_LIMIT` запросов в сутки (UTC); при превышении 429. Запросы из браузерного чата в этот лимит не входят.
- На пользователя — не больше `MAX_TOKENS_PER_USER` активных токенов; лишний можно отозвать.
- Токены и их расход видны в разделе «API-токены» на `/settings` (таблицы `api_tokens`, `api_token_usage`); там же список активных токенов, отзыв и пример вызова `curl` с настоящим адресом сервиса.
- Инструменты чата в `/v1` не попадают: заметка, погода, картинка и pzz остаются витрине. Так платная генерация картинок недостижима по утёкшему ключу.
- `api_check.py` — проверка токена против хоста.

## Где в коде

`app/routes/api.py` — `/v1/models`, `/v1/chat/completions`; `app/auth.py` — выпуск и проверка токенов; `app/routes/pages.py` — `/tokens` (создание и отзыв), `_settings_render` (передаёт адрес сервиса в шаблон); `templates/settings.html` — раздел «API-токены» (якорь `#api`) рядом с разделом «Чат» (якорь `#chat`); адрес в примере `curl` берётся из `app/og.py::public_origin` — `PUBLIC_BASE_URL`, а если он пуст, хост запроса; таблицы `api_tokens`, `api_token_usage`, `usage_logs`.
