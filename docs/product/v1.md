# Версия 1: план и факт

Первая версия — публичная витрина этого репозитория. За основу берём **факт** (уже в коде) и короткий **план** (единственное новое).

Других новых функций в v1 не будет: ни LibreChat, ни корпоративного ACL, ни биллинга, ни второго мессенджера как продукта. Починка вёрстки и дыр — не «новая функция», её можно делать всегда.

Горизонт после v1: [roadmap](roadmap.md).

## Факт — что уже есть

Сводка по коду и `README.md`, не по желаемому.

### Сервис и вход

- Публичный лендинг без обязательного входа.
- Регистрация и сессия: email и пароль.
- Вход через Google и Apple (OAuth), если заданы ключи в `.env`.
- Настройки: предпочитаемая модель чата (`/settings`), не переключатель на экране диалога.

### Чат

- Браузерный UI (React, assistant-ui): поток ответа, список историй.
- Переписка хранится в БД (`Conversation` / `Message`).
- Одна markdown-заметка на чат; шаринга заметок нет.
- Публильная ссылка на чат `/s/<key>`: только чтение, срок, отзыв, журнал заходов.

### Модели и API

- OpenRouter, пользователю видны только free-модели, в публичных id нет `:free`.
- Модель `default` → наверх уходит `openrouter/free`.
- Опционально e7 (Ollama): публичные id вида `e7/<имя>`.
- API-токены `aichat_…`, `GET /v1/models`, `POST /v1/chat/completions`.

### Руки чата (tools)

Это не MCP и не skills. Серверные function tools.

| Рука | Зачем |
|------|--------|
| Дата и время | Актуальные часы сервера / пояс |
| Погода и геолокация | OpenWeatherMap, в т.ч. координаты браузера |
| Картинка | `generate_image`, суточный лимит, файлы в S3 |
| pzz.by | Меню, адрес, заказ (Пицца Лисицца) |
| Заметка чата | Читать и писать markdown-заметку |
| `download_file` | Скачать страницу/текст по URL с защитой от SSRF |

Биллинга нет. Полный денежный журнал — не в v1 (`TODO.md`).

## План — что ещё войдёт в v1

Одно новое:

**Поддержка skills и каталог skills.**

Skill здесь — не очередной tool и не агент LibreChat. Это именованная шпаргалка: как себя вести в теме и какими уже существующими руками пользоваться. Каталог — список таких шпаргалок, который человек может увидеть и выбрать, не собирая агента.

Пока в коде skills нет. Пока их нет — v1 не закрыта по плану, но **факт** выше уже можно показывать людям.

В v1 не добавляем:

- подключение LibreChat;
- корпоративных пользователей как аудиторию этого сайта;
- SSO предприятия, роли, ACL агентов;
- новые бытовые интеграции «в придачу» к skills;
- биллинг и баланс.

Исключение: чинить то, что уже обещано фактом (чат едет, tool молчит, дыра в шаринге).
