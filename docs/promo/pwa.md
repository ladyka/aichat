# Ролик 5. «На телефоне как приложение»

**Длительность:** ~10 минут  
**Тема:** установка на домашний экран и повседневный чат с телефона  
**Аудитория:** мобильная аудитория — метро, очередь, дача

## Сценарий

| Время | Кадр / действие | Текст / голос |
|------:|-----------------|---------------|
| 0:00–0:50 | Человек ищет «чат с ИИ» в магазине приложений, сомневается | «Не обязательно ждать приложение из магазина.» |
| 0:50–2:30 | Браузер → «На экран „Домой“» → иконка → `/chat` | Показать установку с реального экрана |
| 2:30–5:30 | Короткий сценарий дня: погода → «что приготовить из того, что есть» → заметка со списком | Мобильная вёрстка: шапка и поле ввода на месте, скролл только ленты |
| 5:30–7:30 | Выключить сеть (или показать офлайн) → открыть старый чат → **чтение** прошлых ответов | Честно: «Без сети читаете прошлые разговоры. Написать новое сообщение офлайн пока нельзя.» |
| 7:30–8:30 | Снова сеть → новое сообщение | Граница продукта без стыда |
| 8:30–10:00 | Призыв | «Поставьте на домашний экран и держите собеседника рядом.» |

## Честная оговорка

Без сети — только чтение оболочки и прошлых диалогов. Отправить сообщение, завести новый чат или поделиться им офлайн нельзя. Это граница [установки на телефон](../product/v1/pwa.md) в первой версии, а не скрытая недоделка.
