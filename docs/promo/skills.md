# Ролик 4. «Навык вместо повторения одного и того же»

**Длительность:** ~10 минут  
**Тема:** навыки и каталог  
**Аудитория:** учителя, консультанты, те, кто пишет одни и те же просьбы модели

## Сценарий

| Время | Кадр / действие | Текст / голос |
|------:|-----------------|---------------|
| 0:00–1:00 | Человек каждый раз объясняет модели: «Пиши коротко, по-русски, без канцелярита…» | Боль повторения |
| 1:00–3:00 | Страница `/skills`: создать навык — markdown-памятка «как отвечать родителям учеников» | «Навык — не робот и не агент. Это подписанная памятка: как вести себя в теме.» |
| 3:00–5:00 | Новый чат с этим навыком → один короткий вопрос → ответ в нужном тоне | Показать панель «Навыки» в чате |
| 5:00–7:30 | `/catalog` → чужой опубликованный навык → **копия** → свой набор | «Чужой навык берут копией. Чужое под рукой не правят. Своё остаётся своим.» |
| 7:30–8:30 | `/settings#chat`: дефолты для новых чатов | «Один раз выбрали — новые разговоры уже с нужным набором.» |
| 8:30–10:00 | Призыв | «Если устали объяснять одно и то же — оформите это навыком.» |

## Что показать из продукта

- [Навыки](../product/v1/skills.md) — свой навык, каталог, копия, дефолты
- [Чат](../product/v1/chat.md) — панель навыков в разговоре
- [Модели](../product/v1/models.md) — только вскользь: модель выбирают в `/settings`, не на каждом сообщении

## Призыв

«Откройте сайт → войдите → откройте „Навыки“ и напишите первую памятку своими словами»
