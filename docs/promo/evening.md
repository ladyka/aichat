# Ролик 1. «Вечер после работы»

**Длительность:** ~10 минут  
**Тема:** бытовой собеседник — погода, пицца, заметка  
**Аудитория:** 25–45, устали от приложений «на каждый чих»

## Сценарий

| Время | Кадр / действие | Текст / голос |
|------:|-----------------|---------------|
| 0:00–0:40 | Кухня, телефон, дождь за окном. Человек листает пять приложений | «После работы голова полна мелочей: погода, ужин, список дел. Для каждого — своё окно.» |
| 0:40–1:30 | Заставка с названием сервиса, лендинг | «Есть один разговор, в котором всё это можно спросить обычными словами.» |
| 1:30–2:30 | Регистрация за 20 секунд (почта или Яндекс/Google), переход в `/chat` | «Вход как везде. Дальше — пустое поле. Никаких настроек модели на каждом шаге.» |
| 2:30–4:00 | Вопрос: «Какая погода в Минске вечером?» → ход «Узнаю погоду…» → ответ | «Спросили — сервер сам сходил за погодой. Вам не нужно открывать отдельное приложение.» |
| 4:00–6:30 | «Закажи пиццу на дом» → меню pzz → адрес → явное согласие → заказ (наличные курьеру) | «Пицца Лисицца через тот же чат. Перед отправкой на кухню — ваше „да“. Без сюрпризов.» |
| 6:30–8:00 | «Запиши в заметку: завтра купить молоко и оплатить интернет» → правая колонка заметки | «К разговору прикреплена одна заметка. Не теряется между мессенджерами.» |
| 8:00–9:00 | Список чатов слева: вчерашний разговор, автотема | «Истории остаются. Вернуться — один щелчок.» |
| 9:00–10:00 | Призыв: ссылка на сайт, «первый вопрос — любой» | «Не учите платформу. Напишите, как знакомому.» |

## Ключевой кадр для превью

Экран чата с блоком «Узнаю погоду…» и ответом про Минск.

## Что показать из продукта

- [Чат](../product/v1/chat.md) — поток ответа, автотема, список историй
- [Руки](../product/v1/tools.md) — `get_weather`, заказ с pzz.by, заметка чата
- [Вход](../product/v1/auth.md) — почта или OAuth
