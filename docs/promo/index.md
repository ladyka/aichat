# Проморолики

Сценарии десятиминутных роликов о витрине aichat для человека, который **никогда не был на сайте**. Цель — привлечение аудитории, а не обучение уже вошедших.

Обещаем только то, что уже работает в [первой версии](../product/v1/index.md). Функции из [второй версии](../product/v2/index.md) (диктофон, голосовой чат, биллинг и прочее) в сценариях не фигурируют как готовые.

## Общие правила

| | |
|---|---|
| **Герой** | обычный человек в Беларуси (не программист, не «эксперт по ИИ») |
| **Обещание** | «Пишешь как знакомому — получаешь ответ и помощь по делу» |
| **Не говорить** | про Cursor, LibreChat, API-токены, OpenRouter, `:free`, корпоративный вход |
| **Показывать** | реальный экран `/chat`, ход «Узнаю погоду…», заметку, pzz, картинку, сайт `.mzg.by`, навыки, шаринг, установку на телефон |
| **Призыв** | «Откройте сайт → зарегистрируйтесь (почта или Google / Яндекс) → напишите первый вопрос» |

Тон: спокойный, без гиковства, на «вы». Один ролик — одна история жизни; не перечислять все функции списком.

## Универсальный скелет десяти минут

1. **0–1 мин** — жизнь без сервиса (узнавание).
2. **1–2 мин** — дверь: лендинг → вход → пустой чат.
3. **2–8 мин** — одна история с двумя-тремя руками или функциями, без каталога всего.
4. **8–9 мин** — «что это не»: не корпоративная платформа, не редактор кода.
5. **9–10 мин** — призыв и готовая фраза первого сообщения на экране.

### Готовые первые фразы для финала

- «Какая погода у меня?»
- «Помоги составить список дел на завтра»
- «Нарисуй спокойную открытку без текста»
- «Помоги написать короткую страницу обо мне»

Витрина — для [улицы](../product/audiences.md): простой разговор и местный быт. Корпоративный контур и LibreChat в этих роликах не рекламируем.
