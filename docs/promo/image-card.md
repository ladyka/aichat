# Ролик 2. «Картинка к дню рождения»

**Длительность:** ~10 минут  
**Тема:** генерация изображения и шаринг разговора  
**Аудитория:** родители, друзья, мелкая самореклама «на коленке»

## Сценарий

| Время | Кадр / действие | Текст / голос |
|------:|-----------------|---------------|
| 0:00–0:50 | Стол с открытками, поиск «шаблон в интернете», разочарование | «Нужна открытка к празднику. Шаблоны чужие, редакторы сложные.» |
| 0:50–2:00 | Вход в сервис, новый чат | «Попросите картинку своими словами.» |
| 2:00–5:00 | Промпт на русском → генерация картинки → картинка в чате | Показать, что пишут по-человечески: «Открытка: кот и торт, спокойные цвета, без текста на картинке». |
| 5:00–7:00 | «Допиши поздравление» → правка → «Повторить» ответ | «Текст можно переспросить. Переписка остаётся одной веткой, без путаницы.» |
| 7:00–8:30 | «Поделиться» → ссылка `/s/…` → открытие на другом телефоне **только чтение** | «Друг видит разговор по ссылке. Править и писать от вашего имени нельзя. Ссылку можно отозвать.» |
| 8:30–10:00 | Призыв | «Сделайте открытку сегодня вечером — без отдельного „дизайнерского“ сервиса.» |

## Важно в голосе

Не обещать безлимит. Достаточно формулировки: «можно попросить картинку в чате».
