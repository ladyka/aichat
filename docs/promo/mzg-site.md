# Ролик 3. «Свой маленький сайт за один вечер»

**Длительность:** ~10 минут  
**Тема:** заметка чата → публикация на `<имя>.mzg.by`  
**Аудитория:** репетиторы, мастера, волонтёры — кому нужна визитка в сети

## Сценарий

| Время | Кадр / действие | Текст / голос |
|------:|-----------------|---------------|
| 0:00–1:00 | Человек: «Мне бы страничку о себе, но конструкторы — это неделя» | Узнавание |
| 1:00–2:30 | Чат: «Помоги написать страницу: кто я, чем помогаю, как связаться» → текст в заметке | «Сначала — текст в заметке чата. Это и есть содержимое сайта.» |
| 2:30–5:30 | «Создай сайт» → выбор имени → `имя.mzg.by` → «Опубликуй» → явное согласие | «Один сайт на человека. Домен вида имя.mzg.by. Публикация — только после вашего согласия.» |
| 5:30–7:30 | Правка заметки → снова опубликовать → показать обновление | «Изменили текст в заметке — опубликовали снова. Без отдельной „админки“.» |
| 7:30–8:30 | «Какой у меня сайт?» → статус | Спокойная проверка, что всё на месте |
| 8:30–10:00 | Призыв | «Если нужна одна честная страница о себе — начните с разговора.» |

## Чего не обещать

Интернет-магазин, полноценную систему управления сайтом, корпоративный сайт организации.

## Что показать из продукта

- [Чат](../product/v1/chat.md) — заметка справа от переписки
- [Руки](../product/v1/tools.md) — `create_site`, `publish_site`, `site_status` (и при необходимости `update_site`)

## Призыв

«Откройте сайт → войдите → напишите: „Помоги написать короткую страницу обо мне“»
